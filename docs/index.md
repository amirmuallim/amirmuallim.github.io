## Featured Projects

### AHB-APB Bridge — UVM Verification

**UVM · SystemVerilog · AHB · APB · VCS · QuestaSim**

Developed a UVM-based verification environment for an **AHB-to-APB bridge**, including AHB/APB agents, drivers, monitors, sequences, configuration, and scoreboard-based checking.

**Key work:**

- Developed AHB and APB verification components
- Implemented single, incrementing and wrapping transfer sequences
- Built scoreboard-based transaction checking
- Worked with AHB/APB protocol behavior and timing
- Debugged simulation issues using waveforms

[View Project](https://github.com/amirmuallim/AHB-APB-Bridge-Verification)

### UVM Packet Router Verification

**SystemVerilog · UVM · VCS · Verdi · QuestaSim**

Built a UVM-based verification environment for a **1×3 packet router** containing an input interface and three FIFO-based output paths.

**Key work:**

- Developed UVM master and slave agents
- Implemented active/passive verification components
- Created virtual sequencer and scoreboard
- Developed small, medium and large packet tests
- Debugged packet routing and FIFO behavior using simulation waveforms

[View Project](https://github.com/amirmuallim/Router_Verification)

### 8-bit MiniCPU

**Verilog · Digital Design · RTL · Self-Checking Testbench**

Designed and verified an **8-bit CPU** in Verilog with an ALU, register bank and control unit.

**Supported operations include:**

`ASSIGN · INPUT · OUTPUT · ADD · SUB · JUMP · JUMP_POS · JUMP_NEG`

**Key work:**

- Designed the CPU datapath and control logic
- Implemented ALU and register-bank functionality
- Developed a self-checking testbench
- Simulated and debugged RTL behavior using waveform analysis
- Used Icarus Verilog / ModelSim / Vivado for simulation and development

[View Project](https://github.com/amirmuallim/MiniCPU-DesignAndTest)
