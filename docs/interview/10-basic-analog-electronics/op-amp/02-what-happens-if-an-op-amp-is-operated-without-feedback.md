# What Happens if an Op-Amp is Operated Without Feedback?

## Answer

Open-Loop Gain is Extremely High

Output Saturation

Unstable and Non-Linear Behavior

**Comparator applications**: Used to detect threshold crossings (e.g., zero-crossing detector, voltage-level detector).

**Schmitt Triggers**: Uses hysteresis to eliminate noise effects in switching applications.
