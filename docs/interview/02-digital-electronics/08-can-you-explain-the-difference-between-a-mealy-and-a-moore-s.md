# Can you explain the difference between a Mealy and a Moore State Machine? In what situation would you choose one over the other?


In a **Moore machine**, the outputs depend *only* on the current state of the state machine. In a **Mealy machine**, the outputs depend on *both* the current state and the current inputs.

Mealy machine produces async o/p (glitches may occur), less no of states, efficient as compared to Moore machine
