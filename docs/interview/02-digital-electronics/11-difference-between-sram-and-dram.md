# Difference between SRAM and DRAM

## Answer

SRAM and DRAM are both volatile memories, but they store data differently.

| **Feature**  | **SRAM**                   | **DRAM**         |
|--------------|----------------------------|------------------|
| Full name    | Static RAM                 | Dynamic RAM      |
| Typical cell | 6T                         | 1T + 1C          |
| Storage      | Cross-coupled inverters    | Capacitor charge |
| Refresh      | **Not required**           | **Required**     |
| Speed        | Faster                     | Slower           |
| Density      | Lower                      | Higher           |
| Area/bit     | Larger                     | Smaller          |
| Cost/bit     | Higher                     | Lower            |
| Typical use  | CPU caches, small memories | Main memory      |
