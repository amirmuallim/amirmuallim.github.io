# Explain about the Round Robin Arbitration?


An arbitration scheme used when multiple requesters (masters) compete for a single shared resource (a bus, a memory port, a crossbar output, etc.) and only one can be granted access at a time. Round-robin ensures **fairness** — instead of always favoring the same requester (as fixed-priority arbitration does), it rotates priority among requesters so that no single one can starve the others.
